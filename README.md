# Alunissage

Pose le module lunaire en douceur sur une plateforme, avec peu de carburant. Plus la plateforme est petite, plus elle rapporte.

La gravité tire le module vers le sol. Le moteur principal freine la chute, les petits propulseurs le déplacent de côté. Pose-toi lentement et bien droit sur une plateforme, sans tomber en panne sèche.

Ses données (records, réglages) sont rangées dans le dossier du plugin, que NeoDex sauvegarde (synchro cloud comprise).

## Installer

Dans NeoDex : **NeoStore → À découvrir → Alunissage → Installer**.

Développer un plugin : voir le [SDK NeoDex](https://github.com/NDesumeur/neodex-sdk).
